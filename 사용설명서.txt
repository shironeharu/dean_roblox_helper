DEAN ROBLOX HELPER

만든이 : DEAN
디스코드 : ddu._.

――――――――――――――――――――――――――――――

모든 기능은 직관적으로 쉽게 설계하였으며 설명서가 없이
쉽게 누구나 사용 가능합니다

MAC 버전은 따로 문의주세요

추가 기능 건의사항은 디스코드로 부탁드립니다

――――――――――――――――――――――――――――――

 - 잠수도우미

로블록스 창을 자동으로 지정하여 
간격과 키를 지정해 횟수만큼 반복합니다
특징이 있다면 로블록스창을 안보고 있더라도
시간이 되면 자동으로 로블록스창을 띄워 실행하고
이 후 다시 원래 창으로 돌아옵니다

――――――――――――――――――――――――――――――

 - 채팅도우미

한글 타자로 움직이면 이동이 멈추지 않는 버그 편리성 기능
활성화를 시켜두면 로블록스 창에서 항시 발동합니다
 / 를 누르면 채팅창활성화 + 한글타자 변경
 Enter 를 누르면 채팅 보내기 + 영문타자 변경

――――――――――――――――――――――――――――――

 - 클릭도우미

1. 연타
게임에서 연타 클릭이 힘들어서 따로 매크로를 킬 필요 없이 사용가능
온오프 키를 지정하여 좌우 클릭을 활성화시 누르는 버튼을 연타클릭 합니다

2. 클릭 매크로
정해진 간격마다 마우스 클릭을 좌클릭 or 우클릭을 실행합니다
